REGISTRO DE TRABAJOS - PAQUETE PARA GITLAB PAGES

1. Descomprime este ZIP.
2. En GitLab crea un proyecto nuevo.
3. Sube TODOS los archivos y la carpeta icons a la raíz del proyecto.
   Importante: el archivo principal debe llamarse index.html.
4. Activa GitLab Pages / configura el despliegue Pages según el tipo de proyecto.
   Si GitLab no publica automáticamente, añade un pipeline Pages compatible con tu instancia.
5. Abre la URL HTTPS publicada por GitLab Pages desde Chrome en Android.
6. Menú de Chrome (tres puntos) > Instalar aplicación o Añadir a pantalla de inicio.

NOTAS:
- Los registros y datos del transportista se guardan en el almacenamiento local del navegador
  (localStorage). No se sincronizan entre móviles ni entre usuarios.
- La aplicación utiliza Tailwind CSS y SheetJS desde CDN; esas funciones requieren conexión
  a Internet. El contenido principal puede quedar en caché, pero no se garantiza el uso completo
  sin conexión.
- Haz copias de seguridad desde la propia aplicación. Borrar los datos del navegador puede
  eliminar los registros guardados.
